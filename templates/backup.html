🤖 Respaldo automático

Al iniciar la aplicación se genera automáticamente un respaldo diario con todos los datos (tarjetas, transacciones, notificaciones, membresías, productos y movimientos de stock). Se conservan los últimos 30 respaldos en la carpeta backups/.

💡 En Render la base de datos PostgreSQL es persistente; los respaldos automáticos en disco son una capa extra de seguridad. Descarga periódicamente el respaldo completo para guardarlo fuera del servidor.

📥 Restaurar desde respaldo

Sube un archivo JSON previamente exportado. Las tarjetas con el mismo código se actualizan, las nuevas se agregan. Las transacciones, notificaciones, productos y movimientos se suman a los existentes.
