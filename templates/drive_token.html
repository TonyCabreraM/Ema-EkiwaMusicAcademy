Token OAuth (cópialo completo)

Este token permite que la app se conecte a tu Google Drive sin depender de PostgreSQL de Render. Cópialo y pégalo en la variable de entorno GOOGLE_DRIVE_TOKEN de Render para que la conexión sobreviva a los reinicios.

📋 Cómo configurarlo en Render
  1. Copia el token completo con el botón de arriba.
  2. Ve a Render → tu servicio → Environment.
  3. Agrega una variable llamada GOOGLE_DRIVE_TOKEN y pega el token como valor.
  4. Guarda. Render se redesplegará automáticamente.
  5. A partir de ahora, aunque la base de datos se reinicie, la app podrá conectarse a Drive y restaurar el último respaldo automáticamente.
